# 博客一：广告平台的前世今生 — 从传统广告到程序化广告

> 系列文章第 1 篇 / 共 7 篇

## 引言

打开手机刷抖音，信息流里穿插着精准推荐的商品广告；用百度搜索"装修公司"，前几条结果带着"广告"标签；朋友圈里偶尔出现一条看起来像好友动态的推广信息……这些背后，都有一个庞大的系统在运转——**广告平台**。

百度的凤巢、腾讯的广点通（现更名为腾讯广告）、字节跳动的巨量引擎、阿里的阿里妈妈，这些都是国内头部的广告平台。它们每天处理数百亿次广告请求，撑起了互联网公司的核心营收。

这篇文章，我们从历史的角度，看看广告平台是怎么一步步演化到今天的。

---

## 1. 传统广告时代：人工谈判，按位置售卖

在互联网出现之前，广告的形态很简单：

- **报纸广告**：按版面大小和位置定价，头版最贵
- **电视广告**：按时段定价，黄金档 30 秒可能上百万
- **户外广告**：按地段和面积定价，CBD 的大屏幕最抢手

这个时代的特点是：

| 维度 | 特征 |
|------|------|
| 交易方式 | 人工谈判，签合同 |
| 定价模式 | 按位置/时段固定价格 |
| 投放精度 | 粗放，无法精准定向 |
| 效果衡量 | 几乎无法量化 |

广告主的经典困惑："我知道广告费有一半浪费了，但不知道是哪一半。"

---

## 2. 互联网广告 1.0：门户时代的展示广告（1994-2000）

1994 年，AT&T 在 HotWired 网站上投放了世界上第一个 Banner 广告，点击率高达 44%（现在的 Banner 广告点击率通常不到 0.1%）。

这个阶段的互联网广告本质上是**传统广告的线上搬运**：

- 新浪、搜狐、网易等门户网站把首页的广告位当"电子版面"卖
- 按 **CPT（Cost Per Time，按时间计费）** 售卖，比如首页 Banner 一天 50 万
- 广告主找媒体销售谈价格，签 IO（Insertion Order，广告排期单）

```
广告主 → 联系媒体销售 → 谈价格 → 签合同 → 上线广告 → 看报告
```

问题很明显：
- 大广告主才玩得起，中小企业没机会
- 无法按效果付费，钱花了不知道效果如何
- 广告位有限，供需不匹配

---

## 3. 搜索广告的革命：Google AdWords 与百度凤巢（2000-2007）

2000 年，Google 推出了 AdWords（后更名为 Google Ads），这是广告行业的一次根本性变革。

核心创新：

### 3.1 按点击付费（CPC）

不再按展示时间收费，而是用户点击了才收钱。广告主的风险大幅降低。

### 3.2 关键词竞价

广告主对关键词出价，出价高+质量好的广告排在前面。这引入了**市场化定价机制**。

### 3.3 质量度

Google 不只看出价，还看广告质量（相关性、落地页体验等）。这保证了用户体验不会太差。

```
用户搜索 "北京搬家公司"
    ↓
广告系统检索所有竞价该关键词的广告主
    ↓
按 出价 × 质量度 排序
    ↓
展示排名靠前的广告
    ↓
用户点击 → 广告主付费
```

百度在 2009 年推出凤巢系统，替代了之前饱受争议的竞价排名系统，核心逻辑与 AdWords 类似，但针对中文搜索场景做了本地化。

这个阶段的意义：
- **中小企业第一次能以低成本投放广告**（几块钱就能开始）
- **按效果付费**成为可能
- **广告平台**作为独立系统的概念开始成型

---

## 4. 展示广告网络化：Ad Network 的兴起（2005-2010）

搜索广告解决了"用户主动找信息"的场景，但互联网上大量的内容页面（新闻、论坛、博客）上的广告位怎么卖？

**Ad Network（广告网络）** 应运而生。

Ad Network 的角色是**中间商**：
- 聚合大量中小网站的广告位（长尾流量）
- 打包卖给广告主
- 按人群标签分类售卖，而不是按网站售卖

```
[广告主] → [Ad Network] → [网站A, 网站B, 网站C, ...]
                ↑
          聚合流量，分类打包
```

国内典型代表：
- 百度联盟（百度的 Ad Network）
- Google AdSense（Google 的 Ad Network）
- 早期的广点通也有 Ad Network 的影子

问题：
- 多个 Ad Network 之间流量割裂，广告主需要对接多家
- 缺乏统一的竞价机制，定价不透明
- 广告位的价值没有被充分挖掘

---

## 5. 程序化广告时代：RTB 与生态化（2010-2018）

2010 年前后，**RTB（Real-Time Bidding，实时竞价）** 技术的出现，把广告行业推入了程序化时代。

### 5.1 什么是 RTB？

每一次广告展示机会，都通过实时竞价来决定展示哪个广告主的广告。整个过程在 **100 毫秒内** 完成。

```
用户打开网页
    ↓ (10ms)
网站向 Ad Exchange 发送广告请求（携带用户信息）
    ↓ (20ms)
Ad Exchange 向多个 DSP 发起竞价请求
    ↓ (50ms)
各 DSP 根据用户画像、广告主预算等决定出价
    ↓ (10ms)
Ad Exchange 选出最高出价者
    ↓ (10ms)
返回广告素材，展示给用户
```

### 5.2 程序化广告生态的核心角色

这个阶段形成了完整的广告生态：

| 角色 | 全称 | 作用 | 代表 |
|------|------|------|------|
| **DSP** | Demand-Side Platform | 广告主侧，帮广告主买流量 | The Trade Desk, 品友互动 |
| **SSP** | Supply-Side Platform | 媒体侧，帮媒体卖流量 | Google Ad Manager |
| **Ad Exchange** | 广告交易平台 | 撮合买卖双方，实时竞价 | Google AdX, 腾讯 AdX |
| **DMP** | Data Management Platform | 数据管理，提供用户画像 | BlueKai, 百度数据平台 |

```
广告主 → DSP → Ad Exchange ← SSP ← 媒体/App
                    ↑
                   DMP（提供数据支持）
```

### 5.3 国内的特殊格局

与海外开放生态不同，国内头部平台走的是**全链路自闭环**的路线：

- **百度凤巢**：搜索 + 信息流 + 百度联盟，自有流量 + 外部流量
- **腾讯广告（广点通）**：微信、QQ、腾讯新闻等自有流量为主
- **巨量引擎**：抖音、今日头条、西瓜视频等字节系产品
- **阿里妈妈**：淘宝、天猫站内电商广告为主

这些平台同时扮演了 DSP + SSP + Ad Exchange + DMP 的角色，形成了**围墙花园（Walled Garden）**。

---

## 6. 信息流广告与智能化（2015-至今）

2015 年前后，随着移动互联网和推荐算法的成熟，**信息流广告**成为主流。

信息流广告的特点：
- 广告形态与内容高度融合（原生广告）
- 依赖推荐算法进行个性化分发
- 以 **oCPM/oCPC（智能出价）** 为主，平台帮广告主优化转化

```
传统竞价：广告主手动出价，手动调整
    ↓
智能出价：广告主设定转化目标和成本，平台自动优化
    ↓
全自动投放：广告主只需提供素材和预算，平台全权负责
```

这个阶段的标志性变化：
- **字节跳动凭借信息流广告崛起**，巨量引擎成为国内最大的广告平台之一
- 广告投放从"人工优化"走向"算法驱动"
- 短视频广告、直播带货等新形态出现

```
1994  第一个 Banner 广告
  │
  ▼

  │
  ▼

  │

  │

  │

  │

  │
  ▼

```

---

## 小结

广告平台的演进，本质上是沿着三条线在推进：

1. **交易效率**：从人工谈判 → 关键词竞价 → 实时竞价 → 智能出价
2. **精准度**：从按位置投放 → 按关键词投放 → 按人群投放 → 按个体投放
3. **自动化**：从全人工 → 半自动 → 算法驱动 → AI 全自动

理解了这个演进脉络，你就能明白为什么今天的广告平台长成了现在的样子。
