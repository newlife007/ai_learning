# 博客三：广告平台核心概念全解析 — 术语、计费模式、定向方式

> 系列文章第 3 篇 / 共 7 篇

## 引言

和任何专业领域一样，广告平台有一套自己的"黑话"。CPM、CPC、RTB、DSP、oCPX……第一次接触这些术语，很容易一头雾水。

这篇文章把广告平台中最核心的概念梳理清楚，分为三大块：**行业角色与术语**、**计费模式**、**定向方式**。搞懂这些，后面的架构和技术文章就能看得顺畅了。

---

## 1. 行业角色与核心术语

### 1.1 广告生态中的角色

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  广告主   │    │   DSP    │    │Ad Exchange│    │   SSP    │    ┌──────────┐
│Advertiser│───▶│需求方平台 │───▶│ 广告交易所 │◀───│供给方平台 │◀───│  媒体/App │
│          │    │          │    │          │    │          │    │Publisher │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
                                     ▲
                                     │
                                ┌──────────┐
                                │   DMP    │
                                │数据管理平台│
                                └──────────┘
```

| 角色 | 英文 | 说明 | 国内代表 |
|------|------|------|---------|
| 广告主 | Advertiser | 花钱投广告的人/企业 | Nike、拼多多、本地奶茶店 |
| 媒体/发布商 | Publisher | 拥有流量的平台或网站 | 抖音、微信、小红书 |
| DSP | Demand-Side Platform | 帮广告主购买流量的平台 | 品友互动、萃弈(The Trade Desk) |
| SSP | Supply-Side Platform | 帮媒体售卖流量的平台 | Google Ad Manager、Mintegral |
| Ad Exchange | Ad Exchange | 连接 DSP 和 SSP 的交易市场 | Google AdX、腾讯 AdX |
| DMP | Data Management Platform | 管理和分析用户数据 | 百度数据平台、TalkingData |
| Ad Network | Ad Network | 聚合中小媒体流量打包售卖 | 百度联盟、穿山甲 |
| CDP | Customer Data Platform | 广告主自有的用户数据平台 | Segment、神策数据 |

### 1.2 国内平台的"全家桶"模式

需要注意的是，国内头部平台通常把上述角色合为一体：

```
巨量引擎 = DSP + SSP + Ad Exchange + DMP + Ad Network
  └── 广告主在这里投放
  └── 抖音/头条的流量在这里售卖
  └── 竞价在这里完成
  └── 用户数据在这里管理

腾讯广告 = 同上，流量来自微信/QQ/腾讯新闻等
百度营销 = 同上，流量来自百度搜索/信息流/百度联盟
阿里妈妈 = 同上，流量来自淘宝/天猫/优酷等
```

所以在国内，你通常不需要分别对接 DSP、SSP、Ad Exchange，直接用一个平台就够了。

### 1.3 广告层级结构

几乎所有广告平台都采用类似的层级结构来组织广告：

```
账户 (Account)
  └── 广告组 / 推广计划 (Campaign)
        ├── 目标：品牌曝光 / 应用下载 / 商品购买
        ├── 预算：1000元/天
        └── 排期：4月1日 - 4月30日
        │
        └── 广告计划 / 广告组 (Ad Group / Ad Set)
              ├── 定向：18-30岁，男性，运动兴趣
              ├── 出价：20元/转化
              └── 投放位置：信息流
              │
              └── 广告创意 (Ad Creative)
                    ├── 素材：视频/图片
                    ├── 文案："新款跑鞋，限时 8 折"
                    └── 落地页 URL
```

不同平台的命名略有差异：

| 层级 | 巨量引擎 | 腾讯广告 | Google Ads |
|------|---------|---------|------------|
| 第一层 | 广告组 | 推广计划 | Campaign |
| 第二层 | 广告计划 | 广告组 | Ad Group |
| 第三层 | 广告创意 | 广告 | Ad |

## 2. 计费模式

计费模式决定了广告主"为什么付钱"。这是广告平台最核心的商业规则之一。

### 2.1 基础计费模式

| 模式 | 全称 | 含义 | 适用场景 |
|------|------|------|---------|
| **CPM** | Cost Per Mille | 每千次展示付费 | 品牌曝光 |
| **CPC** | Cost Per Click | 每次点击付费 | 网站引流 |
| **CPA** | Cost Per Action | 每次行动付费（注册/下载/购买） | 效果广告 |
| **CPT** | Cost Per Time | 按时间段付费 | 开屏广告、品牌专区 |
| **CPV** | Cost Per View | 每次视频观看付费 | 视频广告 |

用一个例子来理解：

```
假设你投放了一个广告：
  展示了 10,000 次
  被点击了 200 次（点击率 2%）
  产生了 10 个购买（转化率 5%）

不同计费模式下的费用：
  CPM = 50元（假设 CPM 出价 5元）→ 10000/1000 × 5 = 50元
  CPC = 200元（假设 CPC 出价 1元）→ 200 × 1 = 200元
  CPA = 500元（假设 CPA 出价 50元）→ 10 × 50 = 500元
```

### 2.2 智能出价模式（oCPX）

这是当前主流的计费方式，也是各大平台力推的模式。

**oCPX = Optimized Cost Per X**，其中 X 可以是 M（展示）、C（点击）、A（行动）。

核心思想：**广告主按转化目标出价，平台按展示（CPM）计费，中间的优化由平台算法完成。**

```
传统 CPC：
  广告主出价 1元/点击 → 每次点击扣 1元 → 转化好不好平台不管

oCPC（智能出价）：
  广告主说"我希望每个转化成本 50元"
  → 平台预估每个用户的转化概率
  → 对高转化概率的用户提高出价（可能出到 80元 CPM）
  → 对低转化概率的用户降低出价（可能只出 5元 CPM）
  → 最终平均转化成本接近 50元
```

oCPX 的变体：

| 模式 | 含义 | 广告主设定 | 平台优化目标 |
|------|------|-----------|-------------|
| oCPM | 优化千次展示 | 转化出价 | 展示给最可能转化的人 |
| oCPC | 优化点击 | 转化出价 | 点击后最可能转化的人 |
| oCPA | 优化行动 | 行动出价 | 最可能完成行动的人 |

巨量引擎的"放量投放"和腾讯广告的"自动出价"都属于 oCPX 的进一步演化——广告主甚至不需要设定出价，只需要设定预算和目标。

### 2.3 竞价机制：GSP vs VCG

当多个广告主竞争同一个广告位时，谁赢？赢了付多少钱？

**GSP（Generalized Second Price，广义第二价格）**：

```
广告主A 出价 10元
广告主B 出价 8元
广告主C 出价 5元

结果：
  A 赢得展示，但只付 B 的出价 + 0.01 = 8.01元（第二高价）
  而不是自己出的 10元
```

为什么用第二价格？因为它鼓励广告主**如实出价**——你不需要猜别人出多少，出你的真实意愿价就好。

实际上，现在大多数平台使用的是 GSP 的变体，结合了质量度：

```
实际排序分 = 出价 × 质量度 × 预估点击率 × 预估转化率

实际扣费 = 下一名的排序分 / 自己的质量度 + 0.01
```

## 3. 定向方式

定向（Targeting）是广告平台的核心能力——把广告展示给"对的人"。

### 3.1 基础定向

| 定向类型 | 说明 | 示例 |
|----------|------|------|
| 地域定向 | 按地理位置 | 北京市朝阳区、GPS 3公里内 |
| 人口属性 | 年龄、性别 | 18-25岁女性 |
| 设备定向 | 手机品牌、操作系统、网络 | iPhone 用户、WiFi 环境 |
| 时段定向 | 投放时间段 | 工作日 12:00-14:00 |

### 3.2 兴趣与行为定向

| 定向类型 | 说明 | 示例 |
|----------|------|------|
| 兴趣标签 | 用户长期兴趣 | 运动健身、美妆护肤、数码科技 |
| 行为定向 | 近期行为 | 最近搜索过"跑步鞋"、看过运动视频 |
| 关键词定向 | 搜索/浏览关键词 | 搜索过"北京装修公司" |
| 电商行为 | 购物相关行为 | 加购未付款、浏览过竞品 |

### 3.3 高级定向

| 定向类型 | 说明 | 示例 |
|----------|------|------|
| 重定向(Retargeting) | 对已接触过的用户再次投放 | 访问过官网但未下单的用户 |
| Lookalike 扩展 | 找到与种子用户相似的人群 | 上传 1万个已购用户 → 平台找到 100万相似用户 |
| 自定义人群包 | 上传用户 ID 定向投放 | 上传手机号/设备 ID 列表 |
| 排除定向 | 排除特定人群 | 排除已安装 App 的用户 |
| 上下文定向 | 根据内容环境投放 | 在体育类文章旁展示运动品牌广告 |

### 3.4 定向的层级关系

```
定向条件之间通常是"交集"关系：

地域：北京
  ∩ 年龄：18-30岁
  ∩ 性别：女
  ∩ 兴趣：美妆护肤
  ∩ 行为：最近 7 天搜索过"口红"

= 北京的 18-30岁女性，对美妆感兴趣，最近搜过口红

定向越精准 → 人群越小 → 竞争可能越激烈 → 单价可能越高
定向越宽泛 → 人群越大 → 单价可能越低 → 但转化率可能越低
```

### 3.5 DMP 与用户画像

定向能力的基础是**用户画像**，而用户画像来自 DMP：

```
用户画像示例：
{
  "device_id": "xxx-xxx-xxx",
  "age_range": "25-30",
  "gender": "male",
  "city": "上海",
  "interests": ["运动健身", "数码科技", "旅行"],
  "recent_search": ["跑步鞋推荐", "马拉松报名"],
  "recent_app_usage": ["Keep", "Nike Run Club"],
  "purchase_power": "中高",
  "life_stage": "职场新人"
}
```

用户画像的数据来源：
- 搜索历史
- 浏览行为
- App 使用记录
- 电商购买记录
- 位置信息
- 社交关系（间接推断）

## 4. 广告形态

不同的广告形态适用于不同的场景：

### 4.1 主流广告形态

| 形态 | 说明 | 典型场景 |
|------|------|---------|
| 搜索广告 | 搜索结果页的广告 | 百度搜索、淘宝搜索 |
| 信息流广告 | 穿插在内容流中的广告 | 抖音、今日头条、朋友圈 |
| 开屏广告 | App 启动时的全屏广告 | 各类 App 启动页 |
| Banner 广告 | 页面顶部/底部的横幅广告 | 网页、App 内 |
| 插屏广告 | 页面切换时弹出的广告 | 游戏关卡间 |
| 激励视频 | 看完视频获得奖励 | 游戏内看广告得金币 |
| 原生广告 | 与内容形态一致的广告 | 小红书笔记式广告 |

### 4.2 广告素材规格

```
信息流视频广告（以巨量引擎为例）：
  - 横版视频：16:9，1280×720
  - 竖版视频：9:16，720×1280
  - 时长：5-60秒
  - 格式：MP4
  - 大小：≤100MB

信息流图片广告：
  - 大图：1280×720
  - 小图：228×150
  - 组图：3张 228×150
```

## 5. 关键数据指标

做广告投放，必须看懂这些指标：

### 5.1 投放指标

| 指标 | 含义 | 计算公式 |
|------|------|---------|
| 展示量(Impression) | 广告被展示的次数 | — |
| 点击量(Click) | 广告被点击的次数 | — |
| CTR | 点击率 | 点击量 / 展示量 × 100% |
| CVR | 转化率 | 转化量 / 点击量 × 100% |
| CPC | 平均点击成本 | 总花费 / 点击量 |
| CPM | 千次展示成本 | 总花费 / 展示量 × 1000 |
| CPA | 单次转化成本 | 总花费 / 转化量 |

### 5.2 效果指标

| 指标 | 含义 | 说明 |
|------|------|------|
| ROI | 投资回报率 | 收入 / 广告花费 |
| ROAS | 广告支出回报率 | 广告带来的收入 / 广告花费 |
| LTV | 用户生命周期价值 | 一个用户在整个生命周期内贡献的总收入 |
| 留存率 | 用户次日/7日/30日留存 | 广告拉来的用户有多少留下来了 |

### 5.3 一个实际的数据报表

```
日期：2026-04-20
广告计划：春季跑鞋推广
─────────────────────────────────────────
展示量：    500,000
点击量：    15,000    CTR = 3.0%
转化量：    450       CVR = 3.0%
花费：      ¥13,500
─────────────────────────────────────────
CPC：       ¥0.90
CPM：       ¥27.00
CPA：       ¥30.00
─────────────────────────────────────────
转化收入：  ¥67,500（450单 × 平均客单价 ¥150）
ROI：       5.0（每花 1 元广告费赚 5 元）
ROAS：      500%
```

## 6. 归因模型

一个用户可能看了多个广告才最终转化，那这个转化算谁的？这就是**归因**问题。

### 6.1 常见归因模型

```
用户行为路径：
  看到信息流广告 → 搜索品牌词 → 点击搜索广告 → 浏览官网 → 次日直接访问购买

不同归因模型的结果：

最后点击归因（Last Click）：
  100% 归功于搜索广告（最后一次点击）

首次点击归因（First Click）：
  100% 归功于信息流广告（第一次接触）

线性归因（Linear）：
  信息流广告 33% + 搜索广告 33% + 直接访问 33%

时间衰减归因（Time Decay）：
  信息流广告 10% + 搜索广告 30% + 直接访问 60%（越近权重越高）
```

### 6.2 归因窗口

```
点击归因窗口：用户点击广告后 N 天内的转化算广告的功劳
  常见设置：7天、14天、30天

展示归因窗口：用户看到广告后 N 天内的转化算广告的功劳
  常见设置：1天（较短，因为"看到"的影响力弱于"点击"）
```

## 7. 概念关系图

把所有概念串起来：

```
广告主
  │
  ├── 在广告平台创建 Campaign（推广计划）
  │     ├── 设定预算、排期
  │     └── 包含多个 Ad Group（广告组）
  │           ├── 设定定向条件（地域/年龄/兴趣/行为）
  │           ├── 设定出价（CPC/CPM/oCPX）
  │           └── 包含多个 Ad Creative（广告创意）
  │                 ├── 素材（图片/视频）
  │                 └── 文案 + 落地页
  │
  ├── 广告进入竞价
  │     ├── 与其他广告主竞争同一个展示机会
  │     ├── 排序分 = 出价 × 质量度 × 预估CTR × 预估CVR
  │     └── 胜出者展示广告，按 GSP 扣费
  │
  └── 查看数据报表
        ├── 展示/点击/转化/花费
        ├── CTR/CVR/CPC/CPA/ROI
        └── 归因分析
```

## 小结

这篇文章覆盖了广告平台最核心的概念：

- **角色**：广告主、媒体、DSP、SSP、Ad Exchange、DMP
- **计费**：CPM、CPC、CPA、oCPX（智能出价是趋势）
- **定向**：基础属性、兴趣行为、重定向、Lookalike
- **形态**：搜索广告、信息流、开屏、激励视频等
- **指标**：CTR、CVR、CPC、CPA、ROI、ROAS
- **归因**：最后点击、首次点击、线性、时间衰减

这些概念是理解广告平台架构和技术的基础。下一篇，我们进入广告平台的架构设计，看看从广告主创建广告到用户看到广告，中间经历了哪些系统和模块。
