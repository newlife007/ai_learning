# 博客七：广告平台的未来 — AI、隐私计算与行业趋势

> 系列文章第 7 篇 / 共 7 篇（完结篇）

## 引言

前六篇我们系统地了解了广告平台的历史、概念、架构、技术和对接方式。最后一篇，我们把目光投向未来——广告平台正在经历哪些变革？未来 3-5 年会走向何方？

三个核心驱动力正在重塑广告行业：**大模型 AI**、**隐私保护**、**全域营销**。

---

## 1. 大模型 AI 对广告平台的重塑

### 1.1 AI 生成广告创意（AIGC）

这是当前最热、落地最快的方向。

```
传统创意生产流程：
  策划 → 文案 → 设计 → 拍摄 → 剪辑 → 审核 → 上线
  周期：3-7 天
  成本：数千到数万元/条

AI 创意生产流程：
  输入商品信息 + 营销目标 → AI 自动生成文案/图片/视频
  周期：分钟级
  成本：几乎为零

已落地的能力：
  ├── 文案生成：输入商品卖点，自动生成多条广告文案
  ├── 图片生成：基于商品图自动生成多种风格的广告图
  ├── 视频生成：商品图 + 文案 → 自动生成短视频广告
  ├── 数字人口播：AI 数字人自动录制口播视频
  └── 创意变体：一条素材自动生成数十个变体，A/B 测试
```

各平台的 AIGC 布局：

```
巨量引擎：
  - 即创平台：AI 生成图片、视频、文案
  - 智能剪辑：自动混剪素材生成新视频

腾讯广告：
  - 妙思：AI 创意生成工具
  - 智能创意：自动生成多版本素材

百度营销：
  - 擎舵：基于文心大模型的创意生成
  - 智能文案：自动生成搜索广告文案

Google Ads：
  - Performance Max：AI 自动生成和优化创意
  - 生成式 AI 广告素材
```

### 1.2 大模型驱动的智能投放

```
当前的智能投放（oCPX）：
  广告主设定目标 → 平台优化出价和定向
  但广告主仍需要：选择投放目标、设定预算、上传素材、选择人群

未来的 AI 投放（正在演进中）：
  广告主只需要说："我有一款新跑鞋，预算 10 万，希望卖出 1000 双"
  AI 自动完成：
    ├── 分析商品特点，确定目标人群
    ├── 生成多套广告创意（文案+图片+视频）
    ├── 选择最优投放渠道和时段
    ├── 动态调整出价和预算分配
    ├── 实时优化创意（淘汰差的，放大好的）
    └── 生成投放报告和优化建议

本质变化：
  从"人操作工具"→"人设定目标，AI 执行一切"
```

### 1.3 大模型在广告引擎中的应用

```
1. 用户理解升级
   传统：基于标签的用户画像（兴趣：运动、数码）
   大模型：理解用户的深层意图和语义
   例：用户搜索"送女朋友什么礼物好" 
       → 传统系统：匹配"礼物"标签
       → 大模型：理解"有女朋友、想送礼、可能是节日、预算未知"
       → 推荐珠宝/化妆品/鲜花广告

2. 广告与内容的语义匹配
   传统：基于关键词/标签匹配
   大模型：理解内容语义，实现更精准的上下文定向
   例：用户在看一篇"如何提升跑步配速"的文章
       → 大模型理解这是进阶跑者
       → 推荐专业跑鞋而非入门跑鞋

3. 对话式广告
   用户与 AI 助手对话时，自然地融入广告推荐
   例：用户问 AI "推荐一款适合初学者的吉他"
       → AI 回答中自然推荐某品牌吉他（标注为广告）
```

## 2. 隐私保护与数据合规

### 2.1 隐私政策的冲击

```
全球隐私法规收紧：
  ├── GDPR（欧盟，2018）：用户数据需明确授权
  ├── CCPA（加州，2020）：用户有权拒绝数据出售
  ├── 个人信息保护法（中国，2021）：严格限制个人信息处理
  └── 各国持续出台新的隐私法规

平台层面的变化：
  ├── Apple ATT（2021）：iOS 用户需主动授权才能被追踪
  │   → IDFA 获取率从 ~70% 降到 ~25%
  │   → 广告定向和归因能力大幅下降
  │
  ├── Google Privacy Sandbox：逐步限制第三方 Cookie
  │   → Chrome 将不再支持第三方 Cookie（持续推进中）
  │
  └── 各 App 商店加强隐私审查
      → 数据收集需要明确告知用户
```

### 2.2 对广告平台的影响

```
影响一：定向能力下降
  没有 IDFA/Cookie → 无法精准识别用户 → 定向变粗放
  
影响二：归因困难
  无法跨 App/网站追踪用户 → 转化归因不准确
  
影响三：oCPX 效果下降
  转化数据不完整 → 模型训练数据质量下降 → 预估不准

影响四：重定向失效
  无法识别"访问过官网的用户" → 重定向广告效果大打折扣
```

### 2.3 行业的应对方案

```
方案一：隐私计算（Privacy-Preserving Computation）

  联邦学习（Federated Learning）：
    数据不出域，模型参数在各方之间传递
    广告平台 A 和电商平台 B 联合建模，但不交换原始数据
    
    ┌──────────┐         ┌──────────┐
    │ 广告平台  │         │ 电商平台  │
    │ 用户行为  │         │ 购买数据  │
    │ 本地训练  │◀──────▶│ 本地训练  │
    │          │ 交换梯度 │          │
    └──────────┘         └──────────┘
    
  多方安全计算（MPC）：
    多方共同计算结果，但任何一方都无法获得其他方的原始数据
    
  可信执行环境（TEE）：
    在硬件加密的安全区域内处理数据
    数据在使用时也是加密的

方案二：聚合数据替代个体数据

  Apple SKAdNetwork：
    不提供用户级别的转化数据
    只提供聚合的、延迟的、有噪声的转化数据
    广告平台需要适应这种"模糊"的数据

  Google Topics API：
    浏览器根据用户浏览历史，本地计算兴趣主题
    只向广告系统提供粗粒度的兴趣标签（如"运动"）
    而不是具体的浏览记录

方案三：第一方数据战略

  广告主自建数据能力：
    ├── 建设 CDP（Customer Data Platform）
    ├── 收集自有渠道的用户数据（官网、App、CRM）
    ├── 通过广告平台的"数据回传"能力上传第一方数据
    └── 用第一方数据做 Lookalike 扩展

  平台的第一方数据优势：
    巨量引擎有抖音的用户行为数据
    腾讯广告有微信的社交数据
    阿里妈妈有淘宝的电商数据
    → 拥有第一方数据的平台受隐私政策影响较小
```

## 3. 全域营销与跨平台整合

### 3.1 从单平台到全域

```
当前的问题：
  广告主在巨量引擎投了 50 万，在腾讯广告投了 30 万，在百度投了 20 万
  但无法回答：
    - 这三个平台的用户有多少重叠？
    - 用户在不同平台的触达路径是什么？
    - 总体 ROI 是多少？（各平台数据割裂）

全域营销的目标：
  打通多个平台的数据，实现统一的用户触达和效果衡量
```

### 3.2 全域营销的实现路径

```
路径一：广告主自建数据中台
  ├── 统一的用户 ID 体系（手机号/邮箱/会员 ID）
  ├── 各平台数据汇总到自有数据仓库
  ├── 跨平台归因分析
  └── 统一的 ROI 计算

路径二：第三方 CDP/DMP
  ├── 使用第三方平台（如 Segment、神策）聚合数据
  ├── 跨平台人群分析
  └── 统一的受众管理

路径三：平台间数据合作
  ├── 通过隐私计算技术实现跨平台数据协作
  ├── 不交换原始数据，但能联合建模
  └── 目前仍在早期探索阶段
```

## 4. 新兴广告形态

### 4.1 搜索与推荐的融合

```
传统分类：
  搜索广告：用户主动搜索 → 展示相关广告
  推荐广告：平台主动推荐 → 信息流广告

融合趋势：
  抖音搜索广告：用户在抖音搜索 → 展示搜索广告
  小红书搜索：用户搜索 → 笔记式广告
  电商平台：搜索 + 推荐 + 直播 + 短视频，多场景融合

技术变化：
  搜索和推荐共用同一套用户画像和排序模型
  广告主一次投放，多场景自动分发
```

### 4.2 直播电商广告

```
直播间广告的特殊性：
  ├── 实时性：直播间流量波动大，需要实时调整投放
  ├── 转化链路短：看直播 → 直接下单（无需跳转落地页）
  ├── 内容即广告：主播讲解本身就是广告内容
  └── 新指标：GPM（千次观看成交额）、停留时长、互动率

技术挑战：
  ├── 实时预估直播间的转化能力
  ├── 动态调整直播间的流量分配
  └── 直播内容理解（AI 实时分析主播在讲什么商品）
```

### 4.3 AI 对话场景中的广告

```
随着 AI 助手（ChatGPT、文心一言、通义千问等）的普及，
对话场景成为新的广告载体：

用户："推荐一款 3000 元左右的手机"
AI："根据你的需求，以下几款值得考虑：
     1. [品牌A 手机] - 性能均衡... （广告）
     2. [品牌B 手机] - 拍照出色...
     3. [品牌C 手机] - 续航强劲..."

挑战：
  ├── 如何在对话中自然地融入广告，不破坏用户体验
  ├── 如何标注广告，保持透明度
  ├── 如何衡量效果（对话场景没有传统的"展示"和"点击"）
  └── 如何定价（按对话轮次？按推荐次数？按转化？）
```

## 5. 技术趋势

### 5.1 端上智能（On-Device AI）

```
趋势：部分广告决策从云端下沉到设备端

原因：
  - 隐私保护：数据不出设备
  - 低延迟：本地推理更快
  - 离线可用：无网络时也能展示广告

实现：
  - 轻量模型部署到手机端（TFLite、Core ML）
  - 设备端做粗排，云端做精排
  - 设备端计算用户兴趣标签，只上传标签不上传行为数据
```

### 5.2 强化学习在广告中的应用

```
传统方式：
  预估 CTR/CVR → 计算排序分 → 选择最优广告
  每次决策独立，不考虑长期影响

强化学习方式：
  将广告投放建模为序列决策问题
  考虑长期收益：
    - 这次展示低价广告，用户体验好，留存率高，长期收入更高
    - 这次展示高价广告，短期收入高，但用户可能流失

应用场景：
  ├── 广告加载率优化（每页展示几条广告最优）
  ├── 预算分配（跨时段、跨人群的最优分配）
  └── 用户生命周期价值最大化
```

### 5.3 图神经网络（GNN）

```
应用场景：
  ├── 社交关系建模：朋友买了什么 → 你可能也感兴趣
  ├── 商品关系图：买了 A 的人也买了 B
  ├── 反作弊：识别设备农场的关联网络
  └── 冷启动：通过关系图为新用户/新广告找到相似节点
```

## 6. 行业格局展望

### 6.1 国内市场趋势

```
格局变化：
  2020年：字节 > 阿里 > 腾讯 > 百度（广告收入排名）
  2025年：短视频广告持续增长，搜索广告份额下降
  
趋势：
  1. 短视频 + 直播电商继续增长
  2. 搜索广告向多模态搜索演进（图搜、语音搜索）
  3. 私域流量 + 公域广告结合（微信生态）
  4. 出海广告需求增长（TikTok for Business）
  5. AI 降低广告投放门槛，更多中小商家入场
```

### 6.2 技术人才需求

```
广告平台需要的核心技术角色：

算法工程师：
  - CTR/CVR 预估模型
  - 推荐系统
  - NLP/CV（创意理解和生成）
  - 强化学习

后端工程师：
  - 高并发系统设计
  - 分布式系统
  - 实时计算（Flink/Spark）

数据工程师：
  - 数据仓库建设
  - 用户画像系统
  - 实时数据管道

客户端工程师：
  - 广告 SDK 开发
  - 广告渲染优化
  - 端上模型部署
```

## 7. 总结与学习路径

### 7.1 系列回顾

```
博客一：历史演进
  传统广告 → 门户广告 → 搜索广告 → Ad Network → RTB → 信息流 → 智能化

博客二：解决的问题
  广告主：精准投放、效果可量化
  媒体：流量变现最大化
  用户：相关性更好的广告体验

博客三：核心概念
  角色（DSP/SSP/DMP）、计费（CPM/CPC/oCPX）、定向、归因

博客四：架构设计
  投放管理 → 广告引擎（召回→排序→竞价）→ 数据平台

博客五：关键技术
  竞价（GSP）、排序模型（深度学习）、反作弊、Pacing

博客六：API 对接
  Marketing API、SDK 接入、转化追踪、归因

博客七：未来趋势
  大模型 AI、隐私计算、全域营销、新广告形态
```

### 7.2 深入学习建议

```
如果你想进一步深入，推荐以下方向：

入门：
  - 注册一个广告平台账户（如巨量引擎），实际操作投放流程

技术深入：
```

## 结语

广告平台是互联网最复杂的系统之一，它融合了分布式系统、机器学习、实时计算、经济学（拍卖理论）、产品设计等多个领域的知识。

从 1994 年第一个 Banner 广告到今天的 AI 驱动的智能投放，广告平台经历了 30 年的演进。未来，随着大模型、隐私计算、全域营销等技术的发展，广告平台还将继续进化。

希望这个系列能帮你建立起对广告平台的系统性理解。无论你是想进入广告行业、对接广告平台，还是纯粹出于好奇，这些知识都会让你在看到手机上的每一条广告时，多一层理解。
