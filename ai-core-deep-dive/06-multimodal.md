# 多模态大模型：视觉、语音与文本的融合

> 人类通过视觉、听觉、语言等多种感官理解世界。多模态大模型让 AI 也具备了同时处理图像、语音和文本的能力，是通向通用人工智能的关键一步。

## 什么是多模态

```
单模态: 文本 → LLM → 文本
多模态: 文本 + 图像 + 语音 + 视频 → 多模态模型 → 文本/图像/语音
```

多模态模型的核心挑战：**如何将不同模态的信息映射到统一的表示空间，让模型能跨模态理解和推理。**

## 视觉-语言模型（VLM）

这是当前最成熟的多模态方向。

### 架构演进

```
CLIP (2021): 对比学习，图文对齐
  ↓
Flamingo (2022): 视觉编码器 + 交叉注意力 + LLM
  ↓
LLaVA (2023): 视觉编码器 + 线性投影 + LLM（简洁高效）
  ↓
GPT-4V (2023): 原生多模态，端到端训练
  ↓
GPT-4o (2024): 全模态原生，统一架构
```

### CLIP：多模态的基石

CLIP（Contrastive Language-Image Pre-training）用对比学习将图像和文本映射到同一向量空间：

```
训练数据: 4 亿个 (图像, 文本描述) 对

图像 → 图像编码器 (ViT) → 图像向量
文本 → 文本编码器 → 文本向量

目标: 匹配的图文对向量相近，不匹配的向量远离
```

CLIP 的影响深远——几乎所有后续 VLM 都使用 CLIP 的视觉编码器作为"眼睛"。

### LLaVA 架构（主流方案）

```
图像 → ViT 视觉编码器 → 视觉 tokens
                            ↓
                      线性投影层 (将视觉维度对齐到 LLM 维度)
                            ↓
文本 tokens + 视觉 tokens → LLM → 文本输出
```

训练分两阶段：
1. **预训练**：冻结视觉编码器和 LLM，只训练投影层（图文对齐）
2. **指令微调**：解冻 LLM，用视觉问答数据微调

这种"视觉编码器 + 连接器 + LLM"的架构简洁有效，被广泛采用。

### 视觉编码器

| 模型 | 分辨率 | 特点 |
|------|--------|------|
| ViT-L/14 (CLIP) | 224×224 | 最常用基线 |
| SigLIP | 384×384 | Google，效果优于 CLIP |
| InternViT | 448×448 | 大规模视觉编码器 |
| DINOv2 | 可变 | 自监督，细粒度特征好 |

高分辨率处理策略：
- **动态分辨率**：将大图切成多个小块，分别编码后拼接
- **多尺度**：同时使用低分辨率全局特征和高分辨率局部特征

### 代表模型

| 模型 | 机构 | 特点 |
|------|------|------|
| GPT-4o | OpenAI | 全模态原生，能力最强 |
| Claude 3.5 | Anthropic | 视觉理解能力突出 |
| Gemini | Google | 原生多模态训练 |
| Qwen-VL | 阿里 | 开源最强之一，支持中文 |
| InternVL | 上海 AI Lab | 开源，动态分辨率 |
| LLaVA-NeXT | 社区 | 开源标杆 |

## 语音-语言模型

### 语音理解

```
语音 → 语音编码器 (Whisper) → 语音特征
                                  ↓
                            适配器/投影层
                                  ↓
                    文本 tokens + 语音 tokens → LLM → 文本输出
```

Whisper（OpenAI）是最常用的语音编码器，支持多语言语音识别和翻译。

### 语音生成

```
文本 → LLM → 语义 tokens → 声学模型 → 音频波形

代表模型:
  - VALL-E: 3 秒语音克隆
  - Bark: 多语言语音生成
  - ChatTTS: 自然对话语音
```

### 端到端语音对话

GPT-4o 实现了真正的端到端语音对话——直接处理音频输入，直接生成音频输出，无需中间的 ASR/TTS 步骤：

```
传统: 语音 → ASR → 文本 → LLM → 文本 → TTS → 语音
GPT-4o: 语音 → 多模态 LLM → 语音
```

端到端的优势：延迟更低、能理解语气/情感、能生成更自然的语音。

## 图像生成

### 扩散模型（Diffusion Model）

当前图像生成的主流方法：

```
前向过程: 原始图像 → 逐步加噪 → 纯噪声
反向过程: 纯噪声 → 逐步去噪 → 生成图像

训练: 学习每一步的去噪过程
推理: 从随机噪声开始，逐步去噪生成图像
```

### 关键模型

| 模型 | 特点 |
|------|------|
| Stable Diffusion | 开源标杆，Latent Diffusion |
| DALL-E 3 | 文本理解能力强，与 ChatGPT 集成 |
| Midjourney | 艺术质量高 |
| FLUX | Black Forest Labs，新一代开源 |
| Sora | 视频生成，时空一致性 |

### 文本到图像的关键技术

```
文本 prompt → 文本编码器 (CLIP/T5) → 文本条件
                                        ↓
随机噪声 → U-Net/DiT → 条件去噪 → Latent → VAE 解码 → 图像
```

**DiT（Diffusion Transformer）**：用 Transformer 替代 U-Net 作为去噪网络，是 Sora 和 FLUX 的基础架构。Scaling Laws 在 DiT 上同样有效——更大的模型生成质量更好。

## 视频理解与生成

### 视频理解

将视频拆分为帧，用视觉编码器处理后送入 LLM：

```
视频 → 采样关键帧 → 每帧用 ViT 编码 → 时序建模 → LLM
```

挑战：视频帧数多，token 数量爆炸。需要高效的时序压缩策略。

### 视频生成

```
Sora 的核心思路:
  视频 = 时空 patches 序列
  用 DiT 在 latent space 中生成时空一致的视频
```

视频生成的难点：时间一致性（物体不会突然消失）、物理合理性（运动符合物理规律）。

## 统一多模态架构

趋势是将所有模态统一到一个模型中：

```
早期: 每个模态一个专用模型
当前: 视觉编码器 + LLM（模块化）
未来: 原生多模态，所有模态在同一个 Transformer 中处理

Tokenize Everything:
  文本 → text tokens
  图像 → visual tokens (VQ-VAE / patch embedding)
  语音 → audio tokens (EnCodec)
  视频 → spatiotemporal tokens
  
  所有 tokens → 统一的 Transformer → 任意模态输出
```

这种"万物 token 化"的思路正在成为主流方向。

## 实践建议

1. **选择合适的模型**：简单图像描述用开源 VLM 就够，复杂推理考虑 GPT-4o
2. **图像预处理很重要**：分辨率、裁剪方式直接影响效果
3. **prompt 工程**：多模态 prompt 需要明确指出图像中要关注的内容
4. **成本控制**：图像 token 数量多，注意 API 成本

## 小结

多模态是 AI 从"语言智能"走向"通用智能"的必经之路。当前视觉-语言模型已经相当成熟，语音和视频模态也在快速发展。"万物 token 化"的统一架构可能是未来的终极形态。
